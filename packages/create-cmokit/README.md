# create-cmokit

Creates an example CMOkit site: an Astro site for GitHub Pages with one landing-page experiment, its
edge Worker, and the workflow that deploys both. CMOkit works in front of a site on any host or CMS;
this is one way to start.

```
npm create cmokit my-site
```

Part of [CMOkit](https://github.com/cmokit/cmokit), an opinionated, open-source growth engine for
subscription businesses.
