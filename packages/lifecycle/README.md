# @cmokit/lifecycle

The lifecycle, as a Cloudflare Worker or as a container inside an audited product's boundary: lead
capture, the billing tool's webhook events, the product's usage events, and the configured calls to
the product. It keeps no database; credit balances are the billing tool's.

Part of [CMOkit](https://github.com/cmokit/cmokit), an opinionated, open-source growth engine for
subscription businesses. Not yet usable.
