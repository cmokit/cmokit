# @cmokit/lifecycle

The lifecycle, as a Cloudflare Worker: lead capture, the payment processor's webhook events, the
product's usage events, each customer's credit ledger, and the configured calls to the product. The
ledger is a Durable Object per customer; money is the payment processor's.

Part of [CMOkit](https://github.com/cmokit/cmokit), an opinionated, open-source growth engine for
subscription businesses. Not yet usable.
