# CMOkit

An opinionated, open-source growth engine for subscription businesses. The site you already have, on
any host or CMS, one small server part that scales to zero, and bought tools for experiments,
analytics, messaging, billing and payment, wired into a loop that runs from a visitor's first page to their paid subscription and back to the next version of
the page, proposed each week by an agent.
