# CMOkit

An opinionated, open-source growth engine for subscription businesses. A static site you own, one
small server part, and bought tools for experiments, analytics, messaging and payment, wired into a
loop that runs from a visitor's first page to their paid subscription and back to the next version of
the page, proposed each week by an agent.
